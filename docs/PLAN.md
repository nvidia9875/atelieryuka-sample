# アトリエユカ フルリプレイス — デザインサンプル提案サイト 実装計画

> **STATUS (2026-07-15)**: 5案実装後、クライアントFBにより B案(Editorial)・C案(Minimal)を削除、D案は白背景「光のアトリエ」に改訂。現構成は **A: Timeless Classic(a-classic)/ B: Couture 光のアトリエ(b-couture、旧D)/ C: Storytelling(c-story、旧E)** の3案。以下は当初計画の記録。

## 1. 背景と目的

https://atelieryuka.com/ (松尾株式会社「アトリエユカ」/ Shopifyベース) のフルリプレイス案件。
クライアントに **全く方向性の異なる5つのデザイン案** を1つのサイトにまとめて提示し、
1案を選定してもらった後に深掘りする。

### 現行サイトの課題(調査結果)
- 予約導線が弱い。「自宅試着」という最大の強みがトップで埋もれている
- 情報が散漫(ブランド紹介・フォトジャーニー・ニュースが等価に並ぶ)
- 商品名が「MVD-00377-01」等の型番のみで感情が動かない
- 遅延読み込み多用でファーストビュー以外の体感が重い
- モバイルでの入力体験(予約・問い合わせ)が既製Shopifyフォームのまま

### 全案共通のUXゴール
**「ココでドレス頼みたい」と思わせる**こと。そのために:
1. **自宅試着(¥5,500)を全案のファーストCTAに** — 心理的ハードルが最も低い入口
2. **入力しやすい予約UI** — 各案にステップ式予約フォームのデモを実装(日程→衣裳→連絡先)
3. **5ステップの利用フローを必ず可視化** — 「借りて・着て・返すだけ」の簡単さを伝える
4. **価格の透明性** — 価格帯を隠さない(¥198,800〜)
5. **実績・海外フォトジャーニーで信頼と憧れを演出**

## 2. 技術方針(確定事項)

- **静的HTML/CSS/JS**(ビルド不要・1フォルダ完結)
- **写真は現行サイトの実写真**(Shopify CDNからローカルへダウンロードして同梱)
- 外部依存なし: フォントはGoogle Fonts(唯一の外部)、JSはVanilla
- レスポンシブ: 320〜1920px、`prefers-reduced-motion` 対応

## 3. サイト構成

```

├── data/products.json  # Shopify APIから取得済みの生データ(114商品)

├── b-editorial/…
├── c-minimal/…
├── d-couture/…

```

### 共通の情報設計(全案same content、見せ方のみ変える)
1. ヒーロー(ブランド世界観 + 自宅試着CTA)
2. コンセプト/ブランドステートメント
3. コレクション(ウエディング/カラー/タキシード/モーニング 抜粋8〜12点・実価格)
4. ご利用の流れ(01 探す → 02 注文 → 03 受取 → 04 試着/本使用 → 05 返送)
5. 料金・プラン(自宅試着¥5,500 / 本使用3泊4日 / 延長)
6. **予約ステップフォーム(デモ)** — 各案の個性で実装
7. Photo Journey(パリ・ハワイ・NY等 海外ロケフォト)
8. サロン(銀座アトリエ / ハワイサロン)
9. News・実績(著名人・Jリーグアウォーズ)
10. FAQ(抜粋4〜6問)
11. フッター

## 4. 各案デザインスペック

### A案 — Timeless Classic「銀座の正統」
- **世界観**: 現ブランドの正統進化。ラグジュアリーメゾンの品格
- **配色**: 生成り #FBF9F5 / 墨 #2B2724 / シャンパンゴールド #B49B57
- **タイポ**: Cormorant Garamond + しっぽり明朝(見出し)、Noto Sans JP(本文)
- **レイアウト**: センター軸シンメトリー、額縁的余白、細罫線、章番号のローマ数字
- **モーション**: ゆったりフェードのみ。静けさが主役
- **フォーム**: 招待状のような上品なカード式3ステップ

### B案 — Editorial「モード誌」
- **世界観**: VOGUE的ファッションエディトリアル。ドレス=作品
- **配色**: 白 #FFFFFF / 黒 #111 / ボルドー #7A1E2B
- **タイポ**: 巨大Didone(Playfair Display)+ 明朝。雑誌キャプション・ページ番号演出
- **レイアウト**: グリッド崩し・写真オーバーラップ・裁ち落とし、特集見出し「ISSUE 01」
- **モーション**: テキストマスクリビール、微パララックス
- **フォーム**: 誌面アンケート風。下線入力の大きな欄

### C案 — Minimal Concierge「予約特化」
- **世界観**: 「日本一頼みやすいドレスレンタル」。SaaS的機能美
- **配色**: オフホワイト #F7F6F3 / チャコール #21242B / 深緑 #1E4D40(アクション色)
- **タイポ**: Zen Kaku Gothic New + Inter。数字が大きい
- **レイアウト**: Swissグリッド、画面上部に常時「試着予約」バー、価格とフローが常に見える
- **モーション**: 状態遷移のみ。最小限
- **フォーム**: ページの主役。進捗バー付き3ステップウィザード、巨大タップ領域、入力補助

### D案 — Dark Couture「夜のアトリエ」
- **世界観**: オートクチュールのアトリエ。闇に浮かぶドレス
- **配色**: 墨黒 #0E0D0B / アイボリー #F4EFE6 / 金箔 #C9A961
- **タイポ**: Cinzel / Marcellus + 明朝。白抜きの細いレター
- **レイアウト**: フルブリード暗背景、スポットライト的ビネット、横スクロールコレクション
- **モーション**: 遅いKen Burns、金のシマー、ホバーで灯る
- **フォーム**: プライベートサロンのコンシェルジュ予約風(1問1答)

### E案 — Storytelling「Journey」
- **世界観**: 「試着の日から、世界のどこかの結婚式まで」を旅として語る
- **配色**: ブラッシュ #F5E6E0 / アイボリー / スカイブルー #A8C3D1(水彩的)
- **タイポ**: Pinyon Script(英字アクセント)+ Zen Maru Gothic
- **レイアウト**: 章立て縦スクロール(出会い→自宅試着→当日→Photo Journey)、スクロールで物語が進む
- **モーション**: IntersectionObserverでの章リビール、視差、地図的演出
- **フォーム**: 会話形式(チャット風)の入力体験

### index.html — デザインセレクター
- 5案をフルスクリーンカードで比較(コンセプト名・キーワード・雰囲気サムネイル)
- クライアント提示用: 落ち着いたニュートラルなデザインで各案を邪魔しない

## 4.5 デザイン品質基準(導入済みスキル準拠)

`.claude/skills/` に以下を導入済み。**全5案の実装はこれらに準拠する**:

- **baseline-ui** (ibelick): アニメーションは transform/opacity のみ・200ms以内のインタラクションフィードバック・`h-dvh`・safe-area対応・エラーはアクションの隣に表示・ペースト禁止NG・グラデーション原則禁止(世界観として必要な案のみ限定使用)・letter-spacing乱用禁止
- **fixing-accessibility** (ibelick): アイコンボタンに aria-label・全input にラベル・キーボード到達性・focus-visible・フォームエラーは aria-describedby + aria-invalid・見出しレベルスキップ禁止・prefers-reduced-motion
- **web-design-guidelines** (Vercel Labs, `guidelines.md` にローカル保存): `type`/`inputmode`/`autocomplete` 適正・placeholder は「…」+入力例・数値は tabular-nums・見出し text-wrap:balance・画像 width/height 必須・`transition: all` 禁止・touch-action: manipulation・スキップリンク・三点リーダーは「…」・曲線引用符

静的HTML/CSS/JSスタックのため、Tailwind前提の項目(cn utility等)は原則を汲んでVanilla CSSに読み替える。

## 5. 実装ステップ

1. **素材準備**: 実写真をCDNからDL(ドレス・タキシード・ロケフォト 40〜60枚)、`assets/data.js` 作成
2. **index.html(セレクター)実装**
3. **5案を並列実装**(サブエージェント各1案、上記スペック厳守)
4. **検証**: ローカルサーバー起動 → Playwrightで 320/768/1024/1440 スクリーンショット、
   横オーバーフロー・コントラスト・reduced-motion・フォーム動作を確認
5. **品質修正**: スクショレビューで「テンプレ感」があれば個別に磨き込み
